To connect Google Calendar, you need OAuth credentials from Google Cloud Console. You can skip this step and configure it later.

How to get OAuth credentials
  1. Go to Google Cloud Console and create/select a project
  2. Enable the Google Calendar API
  3. Set up the OAuth consent screen (External, add calendar.events scope, add yourself as test user)
  4. Go to Credentials → Create OAuth client ID (Web application)
  5. Add the redirect URI shown below, then copy the Client ID and Secret
