Step-by-step Google Cloud setup
  1. Go to Google Cloud Console and create or select a project
  2. Enable the Google Calendar API
  3. Configure the OAuth consent screen:
    • User Type: External
    • Fill in required fields (App name, User support email, Developer email)
    • On the "Scopes" page, click Add or Remove Scopes, search for calendar.events, check the box, and click Update
  4. Add yourself as a test user (required while app is in "Testing" status):
    • On the "Test users" page, click + ADD USERS
    • Enter your Google email address (the one you'll use to connect)
    • Click Add, then Save and Continue
  5. Go to Credentials → Create Credentials → OAuth client ID
  6. Application type: Web application
  7. Under "Authorized redirect URIs", click + ADD URI and paste:
    {{.RedirectURI}}
  8. Click Create, then copy the Client ID and Client Secret below

How to set up ntfy
  1. Install the ntfy app on your phone (iOS/Android) or desktop
  2. Choose a unique topic name (e.g., schedlock-alerts-abc123)
    • Topics are public by default—use a random, hard-to-guess name
    • Or set up access control for private topics
  3. In the ntfy app, tap + and subscribe to your topic name
  4. Enter the topic name below (Server URL defaults to ntfy.sh)
  5. Optional: For private topics, create an access token at ntfy.sh/account

Telegram
Telegram bot notifications
How to set up Telegram
  1. Open Telegram and search for @BotFather
  2. Send /newbot and follow the prompts to create your bot
    • Choose a name (e.g., "SchedLock Alerts")
    • Choose a username ending in "bot" (e.g., "schedlock_alerts_bot")
  3. Copy the HTTP API token BotFather gives you (looks like 123456:ABC-DEF...)
  4. Get your Chat ID:
    • For personal messages: Message @userinfobot to get your user ID
    • For group notifications: Add the bot to your group, then send a message. Visit https://api.telegram.org/bot<TOKEN>/getUpdates to find the chat ID (negative number starting with -100)
  5. Important: Start a conversation with your bot first (send it any message) or it won't be able to message you

Webhook
Custom HTTP webhook for integrations
How to use webhooks

SchedLock will POST JSON to your URL for each notification event. Use this to integrate with custom systems, home automation, or services without native support.

Payload format:

{
  "event": "approval_requested",
  "timestamp": "2025-01-15T10:30:00Z",
  "request_id": "abc123",
  "operation": "create_event",
  "summary": "Team Meeting",
  "details": "Calendar: primary, Time: ...",
  "approve_url": "https://your-server/approve/abc123",
  "deny_url": "https://your-server/deny/abc123"
}

Event types:

  • approval_requested — New request awaiting approval
  • request_approved — Request was approved
  • request_denied — Request was denied
  • request_timeout — Request expired
  • test — Test notification

Security (HMAC-SHA256):

If you provide a secret, each request includes a signature header:

X-SchedLock-Signature: sha256=<hex-encoded HMAC>

Verify by computing HMAC-SHA256(secret, request_body) and comparing with the header value.

HTTP and local IPs allowed for self-hosted setups
